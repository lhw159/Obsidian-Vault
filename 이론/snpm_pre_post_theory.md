# SPM / SnPM 이론과 그래프 읽는 법 (pre/post 무릎 kinematics)

`scripts/snpm_pre_post.py` 가 하는 일의 원리와, 결과 그래프(`stats_snpm/…png`)가
무엇을 뜻하는지 정리한다. 수식은 터미널/에디터에서 깨지지 않도록 전부 ASCII 로 쓴다.

---

## 0. 한 줄 요약

- 우리 데이터는 각 피험자마다 **0~100% gait cycle 로 정규화된 곡선**(예: flexion(%))이다.
- 이런 **파형 전체**를 pre vs post 로 비교하려면, "한 숫자"로 요약하는 보통 t-test 로는
  부족하다. **각 % 지점마다 t 를 구해 t(q) 곡선을 만들고**, 곡선 전체에 대해 한 번의
  유의수준을 지키도록 **임계선 t\*** 를 세우는 방법이 SPM 이다.
- 우리는 정규성 가정 없이 t\* 를 **순열검정(permutation)** 으로 구한다 = **SnPM**
  (Statistical non-Parametric Mapping).

---

## 1. 문제: 파형(curve) 데이터를 어떻게 비교하나

각 피험자 s 에 대해 우리는 한 곡선을 갖는다:

```
y_s(q),   q = 0, 1, 2, ..., 100   (% gait cycle, 총 Q=101 점)
```

pre 와 post 두 조건이 있고, **같은 피험자**의 pre/post 라 **쌍(paired)** 이다.
알고 싶은 것: "pre 와 post 곡선이 gait cycle 의 **어느 구간에서** 유의하게 다른가?"

### 순진한 방법과 그 함정

방법 A) 곡선을 한 숫자로 요약(예: peak flexion, 평균값) → 그 숫자로 paired t-test.
- 단점: **어디서** 달라졌는지 못 봄. 요약 과정에서 정보 손실. peak 만 보면
  stance 구간 차이를 통째로 놓친다.

방법 B) 101 개 점 각각에서 따로 t-test.
- 단점: **다중비교(multiple comparisons)** 문제.
  점 하나에서 우연히 p<0.05 가 뜰 확률이 5% 인데, 101 번 하면 우연히
  최소 한 곳이라도 뜰 확률은 1 - 0.95^101 ~ **99.4%**. 거의 항상 "가짜 유의"가 뜬다.
  게다가 이웃한 % 점들은 강하게 상관돼 있어(부드러운 곡선) 101 개가 독립도 아니다.

SPM 은 B 의 "점마다 t 를 본다"는 장점은 살리되, 다중비교 문제를 **곡선 전체에 대한
단일 임계선 t\*** 로 정직하게 해결한다.

---

## 2. SPM 의 원리

### 2-1. t(q) 곡선 (Statistical Parametric Map)

paired 이므로 피험자별 **차이 곡선**을 만든다:

```
d_s(q) = post_s(q) - pre_s(q)          (피험자 s 의 pre→post 변화 곡선)
```

각 % 지점 q 에서, n 명의 차이값 { d_1(q), ..., d_n(q) } 에 대해 **1-표본 t** 를 계산:

```
        mean_s d_s(q)
t(q) = ----------------------
        sd_s d_s(q) / sqrt(n)
```

- 분자 = 그 지점에서 pre→post 평균 변화량
- 분모 = 그 변화의 피험자간 흔들림(표준오차)
- t(q) 가 크다 = "변화가 크고 + 피험자들끼리 일관됨"

이렇게 q 를 따라 t 를 쭉 이으면 **t(q) 곡선**이 된다. 이게 그래프 **아래 칸**의 검은 선.
(이름 그대로 statistic 을 map = 파형으로 그린 것.)

### 2-2. 임계선 t\* — 곡선 전체에 대한 하나의 문턱

이제 "t(q) 가 얼마나 커야 유의한가?"의 문턱을 정해야 한다. 핵심은 **점마다 따로
1.96 을 쓰지 않는다**는 것. 대신 **곡선 전체에서 단 한 번이라도 우연히 t\* 를 넘을
확률(= family-wise error, FWE)** 이 alpha(=0.05) 가 되도록 **t\* 하나**를 정한다.

```
P( max_q |t(q)| >= t*  |  실제로는 pre=post )  =  alpha
```

즉 t\* 는 "귀무가설(pre=post) 이 참일 때, 곡선의 최고봉이 이만큼 솟을 확률이 5%인 높이".
곡선이 이 선을 넘는 구간만 유의하다고 본다. 이 t\* 를 구하는 방법이 두 갈래:

- **RFT (Random Field Theory)**: 곡선의 부드러움(smoothness)으로 유효 자유도를 계산해
  이론적으로 t\* 를 구함. 정규성·가우시안 필드 가정 필요.
- **순열검정 (permutation)**: 데이터 자체를 재배열해 경험적으로 t\* 를 구함. **가정 없음.**
  n 이 작을 때 특히 안전. → **우리가 쓰는 SnPM.**

---

## 3. 순열검정(SnPM)의 원리 — t\* 를 데이터로 만든다

### 3-1. 귀무가설을 데이터로 흉내내기: 부호 뒤집기(sign-flip)

paired 설계의 귀무가설은 "pre 와 post 는 차이 없음" = "차이곡선 d_s 의 부호는
**우연**" 이다. 즉 어떤 피험자는 post-pre 로 봤든 pre-post 로 봤든 무의미해야 한다.

그래서 각 피험자의 차이곡선 d_s 에 **+1 또는 -1 을 곱하는** 모든 조합을 만든다:

```
피험자 5명 → 부호조합 2^5 = 32 가지
  (+ + + + +), (- + + + +), (+ - + + +), ..., (- - - - -)
```

각 조합마다:

```
1) 부호 적용한 차이곡선으로 t(q) 를 다시 계산
2) 그 곡선의 최고봉 통계  T_perm = max_q |t(q)|  를 기록
```

32 개의 T_perm 이 모이면, 이것이 **"귀무가설이 참일 때 최고봉이 얼마나 솟는지"의
분포**(귀무분포)다. 여기서 상위 alpha 지점을 잘라 t\* 로 삼는다:

```
t* = (T_perm 들의 상위 5% 분위수)   ← 그래프 아래 칸의 빨간 점선 ±t*
```

우리 관측 데이터(부호 안 뒤집은 원본)의 최고봉을 이 분포와 비교하면 전체 p 값도 나온다:

```
p_overall = (T_perm >= T_observed 인 개수) / (순열 총수)
```

### 3-2. 왜 이게 다중비교를 해결하나 — max 통계의 마법

핵심은 **매 순열마다 곡선 전체의 "최고봉(max)"만 본다**는 점이다.
- 어떤 순열에서 우연히 어느 한 지점이 크게 튀면, 그 큰 값이 max 로 잡혀 귀무분포에
  반영된다.
- 따라서 t\* 는 "우연한 최고봉"까지 포함해서 정해진다.
- 실제 데이터가 이 t\* 를 넘으려면 **우연으로 설명 안 되는 수준**이어야 한다.
- 이웃 점들의 상관(부드러움)도 저절로 반영됨 — 순열마다 실제 곡선을 통째로 쓰니까.

이것이 방법 B(점마다 t-test)가 못한 것을, 별도 가정 없이 자동으로 처리하는 방식이다.

## 4. 기존 t-test 와 무엇이 다른가 (핵심 비교)

| | 보통 paired t-test | SPM / SnPM |
|---|---|---|
| 입력 | 피험자당 **숫자 1개** | 피험자당 **곡선(101점)** |
| 출력 | t 값 1개, p 1개 | **t(q) 곡선** + 유의 **구간** |
| "어디서" 다른지 | 알 수 없음 | **gait cycle 구간으로 정확히** |
| 다중비교 | 없음(비교 1번) | **max 통계 + FWE** 로 통제 |
| 임계값 | t_{0.05, df} (표에서) | **t\*** (RFT 또는 순열로 계산) |
| 분포 가정 | 정규성 | **SnPM 은 무가정**(재배열) |

한 마디로: **SPM 은 "곡선판 t-test"** 이고, 그 대가로 생기는 다중비교 문제를 t\* 라는
단일 임계선으로 막는다. 우리는 그 t\* 를 정규성 가정 없이 순열로 구한 **SnPM** 을 쓴다.

> 참고: 각 % 지점의 t(q) 자체는 그냥 보통의 1-표본 t 다. SPM 이 새로 하는 건
> t 계산법이 아니라, **101 개 t 를 곡선 전체로 놓고 임계선 하나로 판정**하는 부분이다.

## 5. 그래프 읽는 법 (`snpm_<dofs>_<pose>.png`)

세로로 2칸, DOF(flexion/abad/rot) 마다 한 열.

### 위 칸 — pre/post 평균 곡선 + 밴드

```
파란 실선 = pre  피험자 평균 곡선   mean_s pre_s(q)
빨간 실선 = post 피험자 평균 곡선   mean_s post_s(q)
반투명 밴드 = ±1 SD (피험자간 표준편차)   sd_s(q)
회색 세로 음영 = 유의 구간 (t(q) 가 t* 를 넘은 곳)
```

- **실선은 "전체 평균" 맞다** — 정확히는 **피험자들의 평균 곡선**(각 % 에서 n명 평균).
  단, 우리 파이프라인에선 각 피험자 곡선 자체가 이미 그 피험자의 **여러 trial·사이클
  평균**(`average_kinematics.py` 결과)이다. 즉 2단 평균: trial평균(피험자내) → 피험자평균.
- **밴드(경계면 = ±1 SD)** 는 그 지점에서 **피험자마다 값이 얼마나 흩어지는지**.
  밴드가 넓다 = 사람마다 제각각, 좁다 = 일관됨. (표준편차라 약 ±1σ 안에 ~68% 가 든다.)
- pre 밴드와 post 밴드가 **많이 겹치면** 그 구간은 차이가 불확실, **뚝 떨어져 있으면**
  차이가 뚜렷 — 이 직관을 정량화한 게 아래 칸이다.

### 아래 칸 — t(q) 곡선과 임계선

```
검은 선 = t(q)              각 % 에서의 paired t 통계
빨간 점선 = +t* / -t*       순열로 구한 FWE 임계선 (경계면)
회색 음영 = |t(q)| >= t* 구간   → 유의
```

- 검은 선이 **위쪽 점선(+t\*)을 넘음** = post 가 pre 보다 유의하게 큼.
- 검은 선이 **아래쪽 점선(-t\*)을 넘음** = post 가 pre 보다 유의하게 작음.
- 점선 안(±t\* 사이)에 있으면 = 그 구간은 유의하지 않음.

> **경계면(빨간 점선 ±t\*) = "이 높이를 넘으면 우연으로 보기 어렵다"는 문턱.**
> 곡선의 부드러움과 피험자 수까지 반영해 순열로 정한, 곡선 전체에 대한 단 하나의 기준선.

## 6. 우리 설정에서 주의할 점

### 6-1. n=5 의 한계 — p_floor

부호조합이 2^5 = 32 개뿐이라, 관측 데이터가 아무리 극단적이어도 얻을 수 있는 **최소 p** 는

```
p_floor = 2 / 2^n = 2 / 32 = 0.0625   (양측)
```

즉 **n=5 로는 FWE p<0.05 가 원천적으로 불가능**하다. 스크립트가 이 경고를 띄운다.
→ 유의 구간이 떠도 "통계적으로 확정"이 아니라 **기술적(descriptive) 신호**로 해석해야 하고,
   확정하려면 **피험자 수를 늘려야** 한다. (n=6 이면 floor 2/64=0.031 로 0.05 돌파 가능.)

### 6-2. paired(쌍체) 인 이유

같은 사람의 pre/post 라, 개인차(사람마다 원래 다른 무릎)를 **차이 d_s 로 상쇄**한다.
그래서 부호 뒤집기(sign-flip)가 올바른 귀무모형이다(2-표본이면 label 섞기를 쓴다).

### 6-3. 곡선 정렬 전제

모든 피험자 곡선이 **같은 % 그리드(0~100, 101점)** 위에 있어야 점끼리 비교가 된다.
이건 `gait_events.py` 의 HS-HS 정규화가 보장한다. gait cycle 정렬이 틀리면 t(q) 도 틀린다.

## 7. 코드 흐름과의 대응 (`snpm_pre_post.py`)

```
gather()        피험자별 pre/post 평균곡선 로드 → (pre[n,Q], post[n,Q])
snpm_paired()   d = post - pre
                → t(q) 계산                              (2-1)
                → 2^n 부호조합마다 max|t| 모아 귀무분포   (3-1)
                → t* = 상위 alpha 분위수                  (3-2)
                → |t(q)|>=t* 인 연속구간 = clusters
그래프 위칸: pre/post mean±SD + clusters 음영
그래프 아래칸: t(q) + ±t* 점선 + clusters 음영
```

- `--acs plat` 이면 plateau ACS 기준 곡선(`kinematics_plat_avg`)을 읽어
  `stats_snpm_plat/…_plat.png` 로 저장한다(축만 다르고 통계 원리는 동일).

## 8. 요약

1. **SPM = 곡선판 통계지도.** 각 % 에서 t 를 구해 t(q) 곡선을 만든다.
2. **t-test 와의 차이:** 입력이 숫자가 아니라 곡선이고, 101번 비교의 다중비교 문제를
   **max 통계 + FWE 임계선 t\*** 로 막는다.
3. **SnPM:** 그 t\* 를 정규성 가정 없이 **부호 뒤집기 순열**로 데이터에서 직접 만든다.
4. **위 그래프 = 피험자 평균 곡선(±1 SD 밴드).** 밴드=피험자간 흩어짐.
5. **아래 그래프 = t(q) 곡선, 빨간 점선(경계면)=t\* 임계선.** 점선을 넘는 구간이 유의.
6. **n=5 는 p_floor=0.0625** 라 확정 불가 — 지금 결과는 기술적 신호. 피험자를 늘려야 한다.
