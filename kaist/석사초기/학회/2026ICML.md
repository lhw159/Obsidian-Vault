==3DMedAgent: Unified Perception-to-Understanding for 3D Medical Analysis==

이 논문은 **3DMedAgent**라는 새로운 의료 영상 분석 에이전트를 제안합니다. 기존의 CT 영상은 수백 장의 2D 슬라이스로 구성되어 있어 전문가가 직접 검토해야 하는 부담이 크고, 기존 모델들은 주로 2D 중심 설계라서 3D 구조를 이해하는 데 한계가 있었습니다. 연구팀은 이를 해결하기 위해 **2D 멀티모달 대형 언어 모델(MLLM)**을 활용하면서도, 그 결과를 누적·구조화하여 **3D 맥락을 재구성하는 에이전트 아키텍처**를 설계했습니다.

아키텍처는 크게 세 가지 모듈로 이루어집니다. 먼저 **OAMI(Organ-Aware Memory Initialization)**는 여러 슬라이스에서 얻은 정보를 메모리에 통합해 장기별 개요를 형성합니다. 이어서 **CFLT(Coarse-to-Fine Lesion Targeting)**는 병변 후보 영역을 넓게 잡은 뒤 점차 좁혀가며 위치를 특정합니다. 마지막으로 **T1S-Loop(Think-with-1-Slice Loop)**는 필요할 때 특정 슬라이스를 선택해 세밀하게 검증합니다. 이렇게 각 슬라이스별 2D 분석 결과가 독립적으로 끝나는 것이 아니라, **장기적 구조화 메모리**에 차곡차곡 쌓여 최종적으로 3D적 의미를 만들어내는 방식입니다.

연구팀은 성능 평가를 위해 **DeepChestVQA**라는 새로운 벤치마크를 구축했습니다. 이는 흉부 CT 영상을 기반으로 질문을 던지고 모델이 답하는 시각적 질문응답(VQA) 데이터셋으로, 단순 인식뿐 아니라 의학적 추론 능력을 검증할 수 있습니다. 실험 결과, 3DMedAgent는 40개 이상의 3D 의료 과제에서 기존 일반 MLLM, 의료 특화 모델, 3D 전용 모델보다 **20% 이상 높은 정확도**를 기록했습니다. 특히 복잡한 임상 추론 문제에서 성능 향상이 두드러졌고, 다양한 데이터셋과 장기 영역에서도 강한 일반화 능력을 보여주었습니다.

결론적으로, 3DMedAgent는 **CT 슬라이스마다 2D 분석을 수행하고 그 결과를 메모리에 누적해 3D 정보를 추출하는 구조**를 통해, 기존 모델 대비 뛰어난 성능을 입증했습니다. 이는 특수한 3D 모델 학습 없이도 2D MLLM을 활용해 3D CT 분석을 가능하게 했다는 점에서 의미가 크며, 향후 임상 의사결정 지원 시스템으로 발전할 잠재력을 보여줍니다. 다만 실제 의료 적용을 위해서는 **엄격한 임상 검증과 인간 전문가의 감독**이 필수적이라는 점도 강조됩니다.
