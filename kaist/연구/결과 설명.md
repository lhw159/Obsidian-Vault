

# JSW
세 값은 크기 / 일관성 / 우연확률을 각각 나타냅니다. F2 medial 실제 숫자로 풀어 설명하겠습니다.

피험자별 차이(post−pre): +1.41, +1.46, +1.17, +1.37, −0.03

Δ (d) — 평균 차이, mm

Δ = (1.41 + 1.46 + 1.17 + 1.37 − 0.03) / 5 = +1.08 mm
물리적 크기 그 자체. "내측이 평균 1.08mm 열렸다"로 바로 읽힘
부호: + = post가 더 큼(간격 넓어짐), − = 좁아짐
임상 해석·보고의 주 수치
dz — 효과크기 (paired Cohen's dz)

dz = Δ / SD(차이들) = 1.08 / 0.63 = +1.72
"평균 차이가 그 차이들의 흩어짐 대비 몇 배냐" = 변화가 얼마나 크고 일관적인가
기준(Cohen): 0.2 작음 / 0.5 중간 / 0.8 큼 → 1.72는 매우 큼
핵심: 표본 수에 안 휘둘리는 표준화 지표 → n이 작아 p를 못 쓸 때 실질적 주지표
주의: 독립 두 집단의 Cohen's d와 다릅니다(여긴 쌍차의 SD로 나눔)

p — 순열검정 p값
뜻: "pre=post(차이는 우연)가 참일 때, 관측만큼 극단적인 평균차가 나올 확률"
계산: 2⁵=32개 부호조합마다 평균을 내고, |평균| ≥ |관측 평균|인 비율
우리가 p=0.125인 구체적 이유: KS008의 −0.03이 거의 0이라, 그 사람 부호만 뒤집어도 평균이 (1.41+1.46+1.17+1.37+0.03)/5 = 1.09로 관측값 1.08보다 커집니다. 그래서 극단 조합이 2개(원본 + KS008뒤집기), 여기에 ±대칭으로 ×2 = 4/32 = 0.125.

5명 전원이 뚜렷하게 같은 방향이었다면 2/32 = 0.0625(n=5의 바닥)가 나왔을 것


# Grood Suntay
"경골 SI를 대퇴 시상면에 투영해 대퇴 SI와 비교" — 굴곡은 대퇴 ML축(e1) 둘레 회전이고, 대퇴 시상면이 곧 e1에 수직인 평면이라 표준적인 실무 기술과 일치합니다. (엄밀히는 floating축 기준이지만 결과는 같습니다.)

② 내반/외반 — ⚠️ 부분적으로만
GS의 내반외반은 관상면 투영이 아닙니다. 대퇴 ML축(e1)과 경골 SI축(e3) 사이의 실제 3D 각도가 90°에서 얼마나 벗어났는가입니다. 투영 없이 두 축의 비직교성 자체가 각도입니다.

님이 말한 "관상면 투영" 버전은 근사이고, 굴곡·회전이 작을 때만 GS와 거의 같아집니다.
③ 내/외회전 — ❌ 틀렸습니다
"대퇴 SI×대퇴 ML로 만든 AP축을 대퇴 AP축과 비교"는 대퇴 자기 축끼리 비교라 항상 0이 됩니다(자기참조).

올바른 정의: 경골 SI축(e3) 둘레의 회전으로, 경골 AP(또는 ML)축을 floating축 e2와 비교합니다.
실무적 기술로는 "경골 AP축을 대퇴 횡단면에 투영해 대퇴 AP축과 비교"가 맞습니다. → 반드시 경골 축이 들어가야 합니다.
