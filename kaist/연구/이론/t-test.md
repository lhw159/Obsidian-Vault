# **t-test**
두 그룹의 평균을 비교하여 그 차이가 통계적으로 유의미한지 확인하는 기초 통계 기법

두 집단 간의 차이가 없다는 가정 (**귀무가설 ($H_0$, Null Hypothesis):** "두 집단의 평균 차이가 없다.")에서 시작
"만약 두 집단의 차이가 없을 때(귀무가설), 실제 측정된 집단 간의 차이가 나타날 확률이 어떻게 되냐"
를 보는것이 t-test. 즉, 두 집단의 차이가 우연일 확률을 찾는 통계 기법
t 값에 대한 p value를 찾아야 함
![[Pasted image 20260705200731.png]]
t-값이라는게, 노이즈 대비 두 집단의 평균차. t값이 0에 가깝다는건 집단간 차가 거의 없거나, 내부 노이즈가 너무 커서 차이가 우연일 확률이 높다는 것. t 값이 크다는 것은 두 집단 사이 확실한 차이가 있다는 것.

우리의 관심사는 t=0(차이가 없음)이 아니라, 내가 가져온 데이터로 계산한 t-값(예: 2.5)이 "차이가 없다는 세상(t=0이 중심인 세상, 귀무가설)에서 얼마나 감당하기 힘든 황당한 수치인가?"를 따지는 것 (그래서 확률 분포표를 따르는 형태) 이렇게 되면 p value는 P(t>2.5 or t<-2.5) 가 됨

p-value, p<0.05라면 이러한 차이가 우연히 나타날 확률이 5% 미만으로는 것.
